Продукт:      Тренажёр слепой печати для студентов, которые учат свои конспекты, перепечатывая их вслепую.
MVP входит:   Вставка своего текста, загрузка .txt, выбор из 5 готовых конспектов, загрузка случайного конспекта из Википедии по API, автозамена редких символов, посимвольный набор с подсветкой, подсказка клавиши и пальца, блокировка при опечатке до нажатия Backspace, расчёт скорости, точности и проблемных клавиш, сохранение и очистка истории тренировок.
Не входит:    Регистрация и профиль, сервер, соревновательный режим, озвучка клавиш, загрузка .docx/.pdf, графики за год.
Ограничения:  Один HTML-файл (плюс tests.html для автотестов), телефон 360 px, без внешних библиотек, без ключей API; весь интерфейс по-русски.
Как работать: Отдельный commit на задачу · структуру и названия не менять · состояния (пусто, загрузка, ошибка, много данных) обязательны · ошибки показывать словами · ключи не хранить в коде · сначала план по шагам и ждать «да» · не больше двух файлов за шаг · без новых библиотек без спроса · рефакторинг делать отдельным коммитом без изменения поведения · любая библиотека только после проверки по 5 вопросам · технический долг записывать в ДОЛГ.md.
Проверка:     Перед каждым commit открой tests.html и ПРОВЕРКА.md и покажи результат · на каждый критерий приёмки должен быть тест · если тест красный — не коммить и чини код продукта, а не тест · commit разрешён только при всех зелёных тестах.
