Продукт:      Тренажёр слепой печати для студентов, которые учат свои конспекты, перепечатывая их вслепую.
MVP входит:   Вставка своего текста, загрузка .txt, выбор из 5 готовых конспектов, загрузка случайного конспекта из Википедии по API, автозамена редких символов, посимвольный набор с подсветкой, подсказка клавиши и пальца, блокировка при опечатке до нажатия Backspace, расчёт скорости и точности, сохранение истории тренировок.
Не входит:    Регистрация и профиль, сервер, соревновательный режим, озвучка клавиш, загрузка .docx/.pdf, графики за год.
Ограничения:  Один HTML-файл, телефон 360 px, без внешних библиотек, без ключей API; весь интерфейс по-русски.
Как работать: Отдельный commit на задачу · структуру и названия не менять · состояния (пусто, загрузка, ошибка, много данных) обязательны · ошибки показывать словами · ключи не хранить в коде · сначала план по шагам и ждать «да» · не больше двух файлов за шаг · без новых библиотек без спроса.
Проверка:     Критерии приёмки · телефон 360 px · вкладка Network · проверка в режиме Offline.
