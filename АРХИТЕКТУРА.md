Части:         Frontend — один файл index.html. Backend, база данных, вход — нет. Внешний сервис: открытый API случайных цитат/текстов без ключа, прямо из браузера.
Данные:        1) Текст конспекта (строка текста); 2) Результат тренировки (скорость зн./мин, точность %, число ошибок, время). Живут в браузере (localStorage).
Поток:         «Начать тренировку» → очистка символов и проверка посимвольного ввода в браузере → расчёт скорости и точности → сохранение в localStorage → таблица истории.
Люди:          Один человек (студент), без регистрации и входа.
Три вопроса:   Другое устройство — нет (печатает конспекты на своём ноутбуке) · Общие данные — нет (конспекты и статистика личные) · Секреты и ключи — нет (оплаты и закрытых ключей нет). Итог: без сервера.
Дорого менять: Место хранения данных (из localStorage на сервер). Если данные понадобятся на втором устройстве, сломается локальное чтение/запись и появится необходимость в Backend, базе данных, API (GET/POST) и входе пользователя; поэтому все функции работы с localStorage держим в одном месте кода.
Технологии:    HTML, CSS и чистый JavaScript, без фреймворков и внешних библиотек.
