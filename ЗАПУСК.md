Установить:    Любой современный браузер (Chrome 120+, Edge, Safari) и программу GitHub Desktop (для работы с кодом). Установка серверов, Node.js или баз данных не требуется.
Получить код:  Открыть https://github.com/tima665544/typing-trainer → нажать зелёную кнопку «Code» → выбрать «Open with GitHub Desktop» (Clone) или «Download ZIP» и распаковать папку.
Окружение:     Переменные окружения и файл .env не требуются — проект использует открытый API русской Википедии без ключей.
Запустить:     1) В интернете (Production): открыть готовую ссылку https://tima665544.github.io/typing-trainer/ с телефона или компьютера.
               2) На своём компьютере: открыть файл index.html двойным кликом мыши в браузере.
Проверить:     1) Открыть tests.html двойным кликом и нажать «Запустить тесты» — все 6 тестов должны стать зелёными.
               2) Открыть index.html, выбрать в списке «1. Экономика: Спрос и предложение», нажать «Начать тренировку» и набрать текст — в конце появятся скорость и точность.
